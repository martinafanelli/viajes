# Kilometro 0 - Agencia de viajes

Sitio web de una agencia de viajes, desarrollado como proyecto del curso de desarrollo web.

**Sitio publicado:** https://martinafanelli.github.io/viajes/

## Páginas

- Inicio
- Destinos
- Paquetes
- Nosotros
- Contacto

## Tecnologías

- HTML5 semántico
- CSS3 con Grid, Flexbox y diseño mobile-first
- Bootstrap 5.3 (navbar, carousel y modal) por CDN
- Git y GitHub Pages

## Paleta de colores

Chambray `#7A9CB3`, Terracotta `#AD7556`, Sandstone `#DCCFB8`, Muslin `#F1EFE6` y Clove `#53443D`.
